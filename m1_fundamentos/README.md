# Módulo 1. Transformación Digital y Fundamentos de Big Data

Comprender y aplicar los fundamentos de la transformación digital y del ecosistema Big Data para identificar oportunidades de innovación y creación de valor con datos. El programa incluye madurez digital, arquitectura de datos y análisis con Python.

- [Actividad 2](3_tareas/Actividad%202%20Diagn%C3%B3stico%20de%20Madurez%20Digital.docx): diagnóstico de madurez digital.

## Ejecución

No hay `requirements.txt` en este módulo. Revisa los imports antes de preparar el kernel; los notebooks utilizan pandas y librerías de visualización. Abre cada notebook desde su propia carpeta. La actividad 3 descarga `exercise.csv` de Seaborn y requiere conexión. El notebook del proyecto conserva una URL remota con la ruta antigua `homeworks/Tarea%204/`; para usar los CSV locales, ajusta la carga a `data_nacimientos/` desde `4_proyecto/`. La ejecución completa no está validada.
